= Introduction

Semantic Models for VS Code is a Visual Studio Code extension for editing RDF/Turtle documents,
including https://eclipse-esmf.github.io/samm-specification/snapshot/index.html[SAMM Aspect Models,opts=nofollow] of the
https://eclipse-esmf.github.io/esmf-documentation/index.html[Eclipse Semantic Modeling Framework (ESMF),opts=nofollow].

For RDF/Turtle documents, it features syntax highlighting, document outline andautomatic syntax validation.
For SAMM Aspect Models, the extension additionally features Go to Definition for elements and semantic model validation.

== Comparison with the Aspect Model Editor

The https://eclipse-esmf.github.io/ame-guide/introduction.html[Aspect Model Editor,opts=nofollow] provides graphical editing of Aspect Models.
The Semantic Models extension provides direct Turtle editing within VS Code, alongside its search, navigation and Git tools. 
This is ideal for users like software developers, that are familiar with SAMM, RDF/Turtle and VS Code.
